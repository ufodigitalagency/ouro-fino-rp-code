# OF Autoescola

Resource FiveM independente para a Saveiro G3 usada temporariamente nas provas práticas da Autoescola do Ouro Fino RP.

## Integração

- Modelo/spawn: `saveirog3autoescola`
- Texture dictionary: `saveirog3autoescola`
- Handling: `saveirog3autoescola`
- Modkit: `117_saveirog3autoescola_modkit`
- Áudio nativo: `FELTZER3`
- Layout nativo: `LAYOUT_STANDARD`
- Escopo nesta integração: veículo temporário do resource `of_drivingschool`

O rótulo `Saveiro G3 Autoescola` é registrado por `vehicle_names.lua`, seguindo a convenção dos resources de veículos deste repositório. Os arquivos `dlctext.meta`, `global.gxt2`, `content.xml` e `setup2.xml` pertencem ao pacote DLC original e não são necessários neste resource FiveM.

## Origem

Adaptado do pacote GTA V Add-On `98f663-Saveiro G3 auto escola [Add-On].7z`, originalmente distribuído como um DLC `saveirog3autoescola` para instalação via OpenIV.
