# OF Magic Broom

Resource privado do modelo Nimbus 2016 usado pela habilidade `af_witch_broom`.

## Origem

- Autor do modelo: Sg_Mods
- Pacote fornecido pelo proprietario: Nimbus 2016 v1.2
- Tema: Authentic theme
- Spawn FiveM desta conversao: `of_magic_broom`
- Base tecnica: modelo Replace da Akuma convertido em add-on independente

Os arquivos originais permanecem fora deste resource. A conversao renomeia os binarios para evitar qualquer substituicao global da Akuma e reutiliza apenas o layout, o handling e o audio nativos dela por metadata.
